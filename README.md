# Student Class – Java Project

## Description
This project demonstrates the implementation of a Student class using Java and Object-Oriented Programming (OOP).

## Features
- Stores student ID, name, age, and department.
- Uses a constructor to initialize student details.
- Displays student information.
- Updates the student's department.

## Technologies
- Java
- Object-Oriented Programming (OOP)

## Purpose
Created as an academic assignment to demonstrate converting a UML class diagram into Java code.
